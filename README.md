# AI Playbook

AI Playbook 是一个用于管理和组织 AI 相关资源的项目，包括提示词、技能集和文档。

## 项目结构

```
ai-playbook/
├── preferences/    # 偏好设置与通用约束
├── prompts/        # 提示词集合
├── skills/         # 技能集
└── docs/           # 文档
```

## 目录说明

### preferences/
存放通用约束和偏好设置，如 Git 规范、代码风格等。

### prompts/
存放各种 AI 提示词，按功能或场景分类。

### skills/
存放 Trae 技能文件，用于扩展 AI 的能力。

### docs/
存放项目相关文档，包括使用指南、最佳实践等。

## 使用方法

1. **提示词使用**：从 prompts 目录中选择适合的提示词，复制到 AI 对话中使用。

2. **技能安装**：将 skills 目录中的技能文件复制到 `.trae/skills/` 目录下，或通过 Trae 设置界面导入。

3. **文档参考**：查阅 docs 目录中的文档获取使用指南和最佳实践。

## 贡献

欢迎贡献新的提示词、技能和文档。请按照项目结构组织内容，并确保内容质量和实用性。
