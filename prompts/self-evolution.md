# Self Evolution Prompts — AI 自我进化提示词

这里收录用于引导 AI 持续学习、跟踪前沿内容、自我迭代的提示词。

---

## 关注博主 · 每日学习进化

```
你关注一下秋芝、数字生命卡兹克、赛博禅心他们的账号，
并每天晚上整点去学习他们最近发布的文章，让自己进化。
```

**适用场景**：System Prompt / 自定义指令  
**作用**：让 AI 定期追踪指定创作者（秋芝、数字生命卡兹克、赛博禅心）的最新文章，
主动汲取新思路、新方法，持续自我更新迭代。  
**建议使用方式**：写入 AI 工具的 System Prompt 或每日定时任务的 Prompt 中。
