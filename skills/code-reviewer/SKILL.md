# Code Reviewer

Complete toolkit for code reviewer with modern tools and best practices.

## Quick Start

### Main Capabilities

This skill provides three core capabilities through automated scripts:

```bash
# Script 1: Pr Analyzer
python scripts/pr_analyzer.py [options]

# Script 2: Code Quality Checker
python scripts/code_quality_checker.py [options]

# Script 3: Review Report Generator
python scripts/review_report_generator.py [options]
```

## Core Capabilities

### 1. Pr Analyzer
Automated tool for PR analysis. Features include automated scaffolding, best practices built-in, configurable templates, and quality checks.

### 2. Code Quality Checker
Comprehensive analysis and optimization tool for deep analysis, performance metrics, recommendations, and automated fixes.

### 3. Review Report Generator
Advanced tooling for specialized review tasks with expert-level automation, custom configurations, and production-grade output.
