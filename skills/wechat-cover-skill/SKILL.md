# WeChat Cover Skill（公众号封面图生成）

## 简介

基于火山引擎 SeeDream 模型（`doubao-seedream-5.0-lite`）为公众号文章生成封面图，自动裁切去掉 AI 生成标记，保留原图和裁切图。

## 使用方式

在对话中提及"配封面图"或触发此技能时，AI 将：

1. **读取文章内容**，提取主题和关键信息
2. **调用 SeeDream 生成图片**（1920×1920，方形）
3. **自动裁切**：上裁 5%、下裁 10%（去掉右下角 AI 生成标记）
4. **保存双版本**：
   - `cover_original.png` — 原图
   - `cover.png` — 裁切后的封面图
5. **更新文章**，在合适位置添加 `![封面图](文章目录/cover.png)`

## 脚本

`scripts/generate_cover.py` — 生图 + 裁切一体化脚本  
`scripts/crop_cover.py` — 单独裁切已有图片

## Prompt 模板

生成封面图的 prompt 应包含以下要素：

- 文章主题 / 核心概念
- 视觉元素描述（图标、符号、布局）
- 背景风格（渐变、科技感等）
- 文字标题
- 公众号封面适用，1920×1920 方形

## 触发词

配图、配封面图、生成封面图、公众号封面、cover image
