# WeChat Cover Skill（公众号封面图生成）

## 简介

基于火山引擎 SeeDream 模型（`doubao-seedream-5.0-lite`）为公众号文章生成封面图，自动裁切至 2.35:1 并生成 1:1 缩略图。

## 核心理念

**封面图应根据文章内容动态设计，而非套用固定风格。**

我（AI）的工作流：
1. **读取文章** — 理解标题、主题、内容结构、语气调性
2. **设计构图** — 根据文章内容设计视觉方案：布局、色调、视觉隐喻、文字排版
3. **编写 prompt** — 写详细的文生图提示词，包含尺寸、裁切区域、构图要求
4. **调用脚本** — 通过 `--prompt` 传参调用 `generate_cover.py`
5. **脚本处理** — 生图 → 上下各裁 10% → 2.35:1 + 生成 1:1 缩略图 + 保存 prompt 文本

**脚本只负责生图 + 裁切**，prompt 工程由我（AI）在每次调用时根据文章内容实时编写。

## 使用方式

### 生成封面图

当用户提及"配封面图"、"生成封面"、"配图"等触发词时：

1. **读取文章内容**，提取标题、主题、关键看点、语气风格
2. **设计封面方案**：
   - 根据文章内容、技术领域、目标受众设计合适的视觉风格
   - 考虑构图布局、色调氛围、视觉隐喻
   - 如果是技术文章，偏向科技视觉元素；如果是教程类，偏向清晰的信息层级
   - 如果用户指定了方向（"简洁点"、"科技感"、"活泼"），融合用户偏好
   - 如果拿不准，向用户提供 1-2 个方案方向让其确认
3. **编写 prompt 并调用脚本**：根据设计方案编写详细提示词，传入 `--prompt`
4. **展示结果**：显示生成的四个文件路径（原图、2.35:1 裁切图、1:1 缩略图、prompt 文本）
5. **保存 prompt**：prompt 文本自动写入同目录下的 `cover_prompt.txt`，方便排查图片与 prompt 的对应关系
6. **更新文章**：在合适位置添加 `![封面图](文章目录/cover.png)`

### 生成文章总结卡

当用户提及"总结卡"、"课代表总结"、"文章总结图"时：

1. **读取文章内容**，提炼核心观点和关键模块
2. **设计竖版信息图**（1080×1920，适合手机阅读）
3. **编写 prompt 并调用脚本**：传 `--size 1080x1920 --basename summary`
4. **脚本处理**：四周 8% 裁切

## 设计原则（AI 编写 prompt 时的指导）

### 尺寸和比例
- 封面生成尺寸：**2640×1404**（约 1.88:1），裁切后为 **2.35:1**（2640×1123）
- 总结卡生成尺寸：**1080×1920**（竖版），四周 8% 裁切
- 缩略图：从裁切图的 2.35:1 画面中心裁切 **1:1** 正方形（1123×1123）

### 裁切安全区
- **封面（2.35:1）**：上下各裁 10%，对称裁切。
  - 生成图 2640×1404 → 上下各裁 140px（10%）→ 最终 2640×1123（2.35:1）
  - prompt 写明「顶部和底部各留约10%的等高空白背景边距，不放置任何文字或视觉元素」
- **总结卡（竖版）**：四周各 8% 为安全区

### 构图设计参考
- 2.35:1 是宽幅格式，适合**左右分栏**或**路径式**布局（从左到右的旅程/演进）
- 避免上下堆叠的布局（宽幅意味着高度有限）
- 根据文章主题选择视觉隐喻
- 色调与文章调性匹配
- 文字层级清晰：标题突出、关键点标签化、信息来源标注

### 提示词质量要求
- 描述要具体：「深蓝到深黑渐变背景」而非「科技感背景」
- 包含构图要求：「所有文字和视觉元素集中在画面中央区域。顶部和底部各留约10%的等高空白背景边距」
- 明确尺寸（2640×1404）和图文布局
- 指定文字内容（而非通用占位符）
- 指定色调和视觉风格

### 预设 prompt 模板（参考，非强制）

`prompts/` 目录中保留了几套预设风格的 prompt 模板（如深蓝科技信息图、像素窗口风等），可在：
- 用户明确指定某风格时使用
- 直接要求 "用之前的风格" 时使用
- 快速生成候选方案时参考

但**不默认使用**——每次生成应优先根据文章内容动态设计。

## 脚本

- `scripts/generate_cover.py` — 生图 + 裁切（2.35:1）+ 缩略图生成一体化脚本
- `scripts/crop_cover.py` — 单独裁切已有图片（旧用法）
