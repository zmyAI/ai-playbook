# GitHub Workflow Automation

Patterns for automating GitHub workflows with AI assistance.

## When to Use This Skill

- Automating PR reviews with AI
- Setting up issue triage automation
- Creating GitHub Actions workflows
- Integrating AI into CI/CD pipelines
- Automating Git operations (rebases, cherry-picks)

## Core Capabilities

### Automated PR Review
Set up AI-powered PR review workflows with structured feedback (summary, issues, suggestions, security notes).

### Issue Triage
Automate issue labeling, assignment, and routing based on content patterns.

### Git Operations Automation
Automate rebases, branch updates, and workflow triggers via slash commands.

### Repository Configuration
Manage CODEOWNERS, branch protection rules, and repository settings.

## Best Practices

- Store API keys in GitHub Secrets
- Use minimal permissions in workflows
- Cache dependencies, use matrix builds
- Add timeouts and retry logic
