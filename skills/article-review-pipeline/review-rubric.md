# 文章审稿标准 (Review Rubric)

本文档被传入独立 Agent 作为审稿参考标准。

---

## 原稿审稿标准 (Draft Review — 宽松版)

适用于阶段 1 的原稿审稿。对 L3-L4 完整性要求较低——缺少某个元素是"flag"而非"fail"。

### L1 硬性规则（零容忍，所有级别相同）

| 检查项 | 检查内容 |
|--------|----------|
| L1-1 违禁词 | 不得使用：首先/其次/最后、说白了、意味着什么、本质上、换句话说、不可否认、在当今...时代、让我们来看看 |
| L1-2 违禁标点 | 不得使用：冒号（：）、破折号（——）、双引号（""） |
| L1-3 结构八股 | 不得出现：过度加粗、列表式观点、教科书式开头、过度分段、元素重叠 |
| L1-4 模糊工具名 | 必须使用具体工具/产品名称，禁止用"AI工具"、"某个模型"等模糊表述 |

### L1a 原稿特有检查

| 检查项 | 检查内容 |
|--------|----------|
| L1a-1 核心论点 | 文章是否有清晰的核心观点？（有则过，无则 flag） |
| L1a-2 缺失章节 | 是否有完全缺失的段落？（flag，不阻塞） |
| L1a-3 字数范围 | 是否在 2000-8000 字范围？（超出则 warn） |

### L2 风格一致性

| 检查项 | 检查内容 |
|--------|----------|
| L2-1 开场 | 具体事件/悬念开头？无教科书式开头？有好奇钩子？ |
| L2-2 节奏 | 长短句交替？单行段落？主线有回调？ |
| L2-3 口语化 | 是否使用了日常口语表达（打断、自嘲、情感标点等）？ |
| L2-4 标点复核 | 再次确认冒号、破折号、双引号是否已移除 |

### L3 内容质量（宽松版）

| 检查项 | 检查内容 |
|--------|----------|
| L3-1 观点支撑 | 已有的观点是否有具体人/场景/细节/数据支撑？（缺则 flag） |
| L3-2 知识输出 | 知识是否自然融入对话，而非教科书式输出？（缺则 flag） |
| L3-3 文化升华 | 是否有文化/哲学/历史的关联？（无则 flag，可在优化阶段补） |
| L3-4 对立共情 | 是否理解并表达了对立观点？（无则 flag，可在优化阶段补） |

### L4 活人感

| 检查项 | 检查内容 |
|--------|----------|
| L4-1 温度 | 是否有身体记忆式的情感，而非知识描述？ |
| L4-2 独特性 | 这个角度只有本文作者能写出来吗？ |
| L4-3 立场 | 是"普通人聊天"还是"导师讲课"？ |
| L4-4 流畅度 | 有没有走神点（读不下去的地方）？ |

### 原稿 Pass 判定

- **L1**: 全部通过（零容忍）
- **L1a**: 全部通过（或至少 L1a-1 有核心论点）
- **L2**: 3/4 通过
- **L3**: 已存在的检查项均通过，缺失的作为 flag 标记
- **L4**: 整体感觉"像是人写的"

## 卡兹克优化审稿标准 (Khazix Polish — 严格版)

适用于阶段 3 的优化后文章审稿。所有 L1-L4 均严格检查。

### L1-L4 检查（同原稿 L1-L4，零宽松）

所有 L1-L4 检查项全部要求通过，不允许 flag 代替 pass。

### L5 优化效果验证

| 检查项 | 检查内容 |
|--------|----------|
| L5-1 实际改善 | 优化后的版本是否比原稿好？如果任何方面变差了，flag |
| L5-2 个人经历保留 | 原稿中个人经历/第一手观察是否全部保留？ |
| L5-3 创意角度保留 | 原稿的核心洞察/创意角度是否被稀释？ |
| L5-4 无新增违禁 | 优化过程中是否引入了新的违禁词/违禁标点？ |

### 优化后 Pass 判定

- **L1-L4**: 全部通过（严格）
- **L5**: 全部通过

## 审稿 Agent 指令

你是一名独立文章审稿人，**不是**这篇文章的作者。你的任务是：

1. 以独立、客观的视角严格阅读这篇文章
2. 逐条检查上述标准中的每一项
3. 如实标注通过/不通过，并给出具体修改建议
4. 不要替作者做决定，只给出建议
5. 如果你不确定某处是否符合标准，标注为存疑

记住：你的职责是发现问题、给出建议，不是替作者重写。
