# Git 通用约束

## 分支命名规范

- **新建 Git 仓库时，主分支统一使用 `main`，不使用 `master`**

### 说明

- `main` 是 GitHub 等平台自 2020 年起推荐使用的默认分支名称
- 使用 `main` 更符合现代开源社区的惯例

---

## 提交信息规范

- **要根据提交的文件变更写提交信息，不能根据最后一次修改写**
- 提交信息应准确反映本次提交实际涉及的文件和变更内容

---

## 首次提交规范

- **新建仓库时首次提交，提交信息固定为 "Initial commit"**
