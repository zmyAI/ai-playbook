# 通用约束

## 文件修改约束

### README 同步规范

- **修改文件后，需检查 README 是否需要同步更新**
- 检查方式：从当前目录一层一层向上查找，直到仓库根目录或合适位置
- 更新原则：
  - 创建/删除目录、重大结构调整 → **需要同步**
  - 目录内的具体细节（如某条具体约束） → **无需同步**

### 示例

| 修改内容 | README 是否同步 |
|---------|----------------|
| 创建 `preferences/` 目录 | ✅ 需要 |
| 在 `preferences/` 内添加 Git 规范文件 | ❌ 无需 |
| 修改项目整体结构 | ✅ 需要 |

## 技能同步规范

- **修改/新建技能时，如果对应同步目录中有同名技能，必须同步更新**
- 技能分类规则：
  - **公共技能**（默认）→ 同步到 `D:\github\zmyAI\ai-playbook\skills\`，内部路径使用**相对路径**
  - **私有技能**（用户明确说明）→ 同步到 `D:\github\zmyAI\.trae\skills\`，内部路径保留**绝对路径**（如 `D:\github\zhaomy2025\digest\`，无需修改）
- 判断依据：用户明确说明私有技能或放到 `.trae\skills` 即为私有技能
- 检查方式：修改/新建技能前，先确认是否为私有技能，再选择对应同步目录
- 同步原则：优先使用 replace_in_file 修改差异部分，避免整文件覆盖
