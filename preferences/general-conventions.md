# 通用约束

## 文件修改约束

### README 同步规范

- **修改文件后，需检查 README 是否需要同步更新**
- 检查方式：从当前目录一层一层向上查找，直到仓库根目录或合适位置
- 更新原则：
  - 创建/删除目录、重大结构调整 → **需要同步**
  - 目录内的具体细节（如某条具体约束） → **无需同步**

### 示例

| 修改内容 | README 是否同步 |
|---------|----------------|
| 创建 `preferences/` 目录 | ✅ 需要 |
| 在 `preferences/` 内添加 Git 规范文件 | ❌ 无需 |
| 修改项目整体结构 | ✅ 需要 |
